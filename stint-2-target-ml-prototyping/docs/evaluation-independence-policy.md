# Evaluation Independence Policy

## Purpose

This policy defines when STINT 2 evaluation labels can support interpretable model metrics.

STINT 1 delivered evidence, denominators, and candidate/proxy labels. It did not deliver an independently labeled dataset. STINT 2 must therefore build the evaluation frame before reporting model performance.

## Evaluation Independence Values

| value | definition |
|---|---|
| `independent` | Annotator assigned without seeing the pipeline proposal or generated label. |
| `human_validated` | Annotator confirmed or rejected a proposal. |
| `derived_from_rules` | Generated by a rule set, embedding model, crosswalk, or other pipeline mechanism. |

## Rule

A metric is interpretable only when `evaluation_set_type` is declared.

A classifier may not be evaluated against labels produced by the same mechanism it uses.

No F1, accuracy, precision, recall, coverage, confidence, or production-readiness metric may be reported unless the evaluated records are independent from the evaluated mechanism or the report explicitly declares the dependency.

## Required Fields On Every Evaluation Record

Every evaluation record must carry:

- `target`
- `physical_record_id` or approved STINT 2 record proxy
- `source_path`
- `contractor_path`
- `stratum`
- `evaluation_set_type`
- `evaluation_independence`
- `label_generation_method`
- `annotator_id`
- `excluded_mechanisms`
- `excluded_from_training`
- `excluded_from_tuning`

## Mechanism Exclusion

`excluded_mechanisms` must name every mechanism that is not allowed to train on, tune on, or evaluate itself against the record.

Examples include:

- lexical rule set
- embedding nearest-neighbor model
- catalog crosswalk
- semantic classifier
- threshold optimizer

## Forbidden Uses

Frozen evaluation records must not be used for:

- model training
- rule construction
- feature selection
- semantic prompt calibration
- threshold selection
- error-analysis driven relabeling without versioned split controls

## Reporting Boundary

If `evaluation_independence = derived_from_rules`, any reported result is a pipeline-consistency diagnostic, not an independent performance metric.
