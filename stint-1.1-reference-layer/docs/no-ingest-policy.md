# No-Ingest Policy

This project distinguishes useful references from ingestible references.

The following must not be ingested as authoritative source material:

- Loose alarm/code lists without provenance.
- Author-created code tables without validation path.
- Re-uploaded datasets with unclear lineage.
- Community dictionaries or forum-derived vocabularies.
- Sources that cannot be licensed, cited, or traced.

The following can be used only as discovery hints, never as ground truth:

- Search snippets.
- Unversioned blog posts.
- Presentation fragments without source metadata.
- Agent-generated summaries.

If a discarded source suggests a useful concept, the concept must be corroborated through an accepted source before entry into the reference layer.
